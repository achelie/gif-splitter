How to extract frames from a GIF

Turn an animated GIF into individual PNG images, inspect the sequence, and save only the frames you need. Everything happens locally in your browser.

Updated October 4, 2026 · About 5 minutes

In this guide

  1. Choose your GIF
  2. Inspect frames and timing
  3. Download PNGs or a ZIP
  4. Understand transparency and disposal
  5. Handle large or damaged files

1. Choose a GIF from your device

Open GIF Frame Extractor and select a local GIF, or drag a GIF onto the upload area. The browser reads the file on your device and starts decoding its animation. There is no account to create, and the selected file is not uploaded to a server.

Use the original GIF file when possible. An image copied from a page, a screenshot, or a file that was converted to another format may contain only one still image. Renaming another file with a .gif extension does not turn it into a GIF.

The current file size limit is 30 MB. Files also need to fit within the tool's decoded-image safeguards, because the compressed file size does not tell you how much memory its frames will require.

2. Inspect the actual frames and their timing

After decoding finishes, browse the frame grid. Each item represents a frame in the GIF's stored sequence. Select the frames that contain the pose, expression, transition, or visual detail you need.

Check the frame timing when the rhythm of an animation matters. GIFs can assign different delays to different frames: one image may remain visible much longer than the next. Frame count alone therefore does not describe the playback speed.

Some GIFs contain consecutive frames that look identical. These can still be separate frames with their own timing. This extractor reads the stored frame sequence rather than sampling the animation at a fixed number of screenshots per second. Browser playback can also clamp very short delays, so observed playback speed may differ from the stored timing.

3. Save a PNG or download a ZIP

Use the download control on an individual frame to save it as a PNG. This is convenient when you need a single still image for a reference, presentation, or further editing.

For several frames, select the ones you want and download the selection as a ZIP. To keep the entire sequence, use the option to download all frames. Unzip the download on your device to access the PNG files individually.

A ZIP is a package of still images; it is not a playable animation. Likewise, a PNG export contains the pixels for that frame, but it does not preserve the GIF's looping behavior or frame delay as animation instructions. Keep the original GIF if you may need those properties later.

Why transparency and disposal matter

A GIF does not always store a complete picture for every frame. To save space, it may store a small rectangle containing only the area that changes. Decoding those rectangles as separate pictures would produce fragments instead of the image you saw while the animation was playing.

To create a useful still, an extractor combines those updates on the GIF's full canvas. It also follows the animation's disposal instructions: a frame may leave its pixels in place, clear its area before the next frame, or restore the preceding image. These rules help prevent trails, missing backgrounds, and leftover objects in later frames.

Transparent areas need similar care. GIF supports a transparent palette entry rather than the smooth partial transparency available in PNG. Exporting to PNG preserves the decoded result, but it cannot invent softer edges or colors that were not present in the source. A checkerboard behind a preview indicates transparency; it is not intended to become part of your downloaded image.

If a GIF will not extract

A small compressed GIF can require substantial memory once decoded. Canvas width, canvas height, and total frame count all contribute. The tool applies safeguards to limit decoded image data, so it may reject a file under 30 MB when the expanded sequence would be too large.

Available memory also varies by device and browser. If processing fails, close other memory-heavy tabs and try a smaller GIF. Reducing the dimensions or shortening the animation in an image editor can help. A damaged or incomplete download may need to be downloaded again from its original source.

If you see only one frame, the file may be a static GIF. If a saved frame looks different against a new background, inspect whether it contains transparency. Always compare the result with the source before using it in a final project, and use images you own or have permission to reuse.
