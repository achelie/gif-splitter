## Free 运行方案

当前 `ADSENSE_MODE=off`：80 个 HTML 页面与 GIF 工具由纯静态 Pages 提供。产物没有 `_worker.js` 或 `_routes.json`；GIF 解码、合成、PNG 和 ZIP 在浏览器完成，因此本次页面和工具不执行 Functions，不依赖 Workers Free 的请求/CPU 配额。静态 CSP 使用精确 SHA-256、明确脚本来源与安全响应头，HTML 无 nonce 占位符。[Cloudflare 静态与 Functions 计费](https://developers.cloudflare.com/pages/functions/pricing/)

未来 `consent`/`live` 构建保留 nonce Worker，在实际 Functions 配额、fail-closed、Google Ready、CMP 与单元 ID 核验后另行启用；本轮没有升级套餐、改变账号权限或启用广告。
